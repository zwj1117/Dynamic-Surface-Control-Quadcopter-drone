# 基于动态面控制 (DSC) 的四旋翼无人机轨迹跟踪仿真
本项目基于 MuJoCo 物理引擎，实现了一个四旋翼无人机的三维轨迹跟踪控制系统。控制器采用 **动态面控制** 算法作为位置外环，结合 **PD 控制** 作为姿态内环，通过混控矩阵将控制指令分配至四个旋翼。

## ✨ 项目特性
1. **动态面控制 (DSC)**：在传统反步法基础上引入一阶低通滤波器，避免了虚拟控制量逐层求导导致的“微分爆炸”问题，降低了计算复杂度并提高了系统鲁棒性。
2. **双层控制架构**：
   - **外环 (位置环)**：基于 DSC 算法计算期望推力与期望姿态角。
   - **内环 (姿态环)**：基于 PD 控制计算滚转、俯仰、偏航力矩。
3. **初始化修复**：针对 DSC 算法启动瞬间滤波器滞后导致的“掉高”问题，加入了初始虚拟控制量预计算，确保平滑起飞。
4. **复合轨迹跟踪**：支持 XY 平面圆周运动与 Z 轴正弦振荡复合的三维螺旋轨迹跟踪。
5. **X型混控分配**：通过 4x4 混控矩阵将总推力与三轴力矩精确分配至四个旋翼。

## 🧩 系统架构
控制系统的信号流向如下所示：
```text
期望轨迹 (x_d, v_d)
      │
      ▼
┌─────────────────────────────────────────────┐
│           位置外环 (DSC 算法)                 │
│  1. 误差面 z1 = x - x_d                       │
│  2. 虚拟控制量 α = v_d - k1·z1                 │
│  3. 一阶滤波: α̇_f = -(α_f - α) / τ           │
│  4. 误差面 z2 = v - α_f                       │
│  5. 控制律 u = -k2·z2 + α̇_f - z1              │
└─────────────────────────────────────────────┘
      │ (输出: ux, uy, uz)
      ▼
┌─────────────────────────────────────────────┐
│           推力与姿态解算                      │
│  F_total = m·(uz + g)                        │
│  θ_d = f(ux, ψ)  φ_d = f(uy, ψ)             │
└─────────────────────────────────────────────┘
      │ (输出: F_total, 期望姿态角)
      ▼
┌─────────────────────────────────────────────┐
│           姿态内环 (PD 控制)                  │
│  τ = J·(Kp·e - Kd·ω)                         │
└─────────────────────────────────────────────┘
      │ (输出: 三轴力矩 τ_roll, τ_pitch, τ_yaw)
      ▼
┌─────────────────────────────────────────────┐
│           混控分配矩阵                        │
│  [F_total, τ_roll, τ_pitch, τ_yaw]^T = A·[m1,m2,m3,m4]^T │
└─────────────────────────────────────────────┘
      │ (输出: 电机推力 m1~m4)
      ▼
   MuJoCo 物理引擎仿真
```

## 💻 环境依赖
在运行代码之前，请确保您的 Python 环境已安装以下依赖库：
- Python >= 3.8
- MuJoCo >= 3.0.0
- NumPy
- SciPy
安装依赖：
```bash
pip install mujoco numpy scipy
```
> **注意**：请确保运行目录下存在有效的 MuJoCo 场景文件 `scene.xml`，且模型中包含名为 `x2` 的机体以及 `thrust1`~`thrust4` 的站点标记。
---
## 🚀 快速开始
1. 准备好场景文件 `scene.xml`。
2. 运行主控制脚本：
   ```bash
   python DSC.py
   ```
3. MuJoCo 仿真窗口将自动弹出，无人机将开始跟踪预设的三维螺旋轨迹。
4. 终端会实时打印目标位置、实际位置与跟踪误差。

## ⚙️ 核心参数说明
在 `DSC.py` 的头部定义了控制器的核心参数，您可以根据实际需求进行调整：
### 轨迹参数
| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `trajectory_radius` | 0.8 | XY平面圆周运动半径 |
| `trajectory_omega` | 0.4 | XY平面圆周运动角速度 |
| `trajectory_z_amp` | 0.3 | Z方向正弦振荡幅值 |
| `trajectory_center` | (1.0, 1.0, 1.0)| 轨迹中心坐标 |
### 控制器参数
| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `k1` | 2.0 | 位置环收敛增益 |
| `k2` | 5.0 | 速度环收敛增益 |
| `tau` | 0.05 | DSC一阶滤波器时间常数 (越小跟踪越快但越接近反步法，越大越平滑) |
| `Kp_att` | 120.0 | 姿态环比例增益 |
| `Kd_att` | 30.0 | 姿态环微分增益 |
| `max_tilt` | 0.6 | 最大倾斜角限制 (防失速) |
